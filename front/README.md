# 🏥 غيث - Ghaith Medical Services

موقع خدمات طبية متكامل يربط بين المرضى والممرضين المسجلين بالنقابة.

## 🚀 التشغيل

```bash
npm install
npm run dev
```

سيفتح الموقع على: `http://localhost:5173`

## 🔌 ربط الباك اند (Backend)

**جميع الـ endpoints معرفة في ملف واحد: `src/services/api.ts`**

### طريقة الربط:

1. افتح ملف `src/services/api.ts`
2. غيّر `BASE_URL` إلى رابط الباك اند الخاص بك:

```ts
// 🔧 غيّر هذا السطر فقط
export const BASE_URL = import.meta.env.VITE_API_URL || 'http://localhost:8000/api/v1';
```

أو استخدم متغير البيئة في `.env`:

```
VITE_API_URL=http://localhost:8000/api/v1
```

### الباك اند المتوقع

هذا الفرونت اند متصل بـ **Django REST API** في:

| المشروع | المسار |
|---------|--------|
| Backend | `../back/patient-nurse-api/` |
| Port | `8000` |
| API prefix | `/api/v1/` |

### خريطة الـ endpoints (Frontend → Backend):

| الوظيفة | Frontend endpoint | Backend endpoint |
|---------|-------------------|-----------------|
| Login | `auth/login/` | `/api/v1/auth/login/` |
| تسجيل ممرض | `auth/register/nurse/` | `/api/v1/auth/register/nurse/` |
| تسجيل مريض | `auth/register/patient/` | `/api/v1/auth/register/patient/` |
| الملف الشخصي | `profile/` | `/api/v1/profile/` |
| الخدمات | `services/` | `/api/v1/services/` |
| المناطق | `areas/` | `/api/v1/areas/` |
| إحصائيات الموقع | `stats/` | `/api/v1/stats/` |
| طلبات الممرض | `nurse/orders/active/` | `/api/v1/nurse/orders/active/` |
| طلبات المريض | `patient/orders/` | `/api/v1/patient/orders/` |
| لوحة الإدارة | `admin/...` | `/api/v1/admin/...` |

### تنسيق الاستجابة (Response Format)

الباك اند يستخدم تنسيق موحد:
```json
{
  "success": true,
  "message": "...",
  "data": { ... }
}
```

الفرونت اند يقوم تلقائياً بـ:
- فك تغليف `data` من الاستجابة
- تحويل أسماء الحقول من `snake_case` إلى `camelCase`
- استخدام بيانات تجريبية (Mock Data) في حالة عدم توفر الباك اند

## 🎯 المميزات

### 📌 الصفحة الرئيسية
- عرض خدمات الموقع
- إحصائيات (طلبات يومية، ثقة العملاء، ممرضين نشطين)
- اختيار نوع الحساب (ممرض / مريض)
- زر واتساب عائم للتواصل

### 👨‍⚕️ الممرض
- **التسجيل:** اسم، تليفون، إيميل، عنوان، محفظة (اختياري)، جنس، باسورد، صورة شخصية، شهادة التخرج، كارنية النقابة، ميعاد المقابلة
- بعد موافقة الأدمن:
  - الرئيسية: طلبات نشطة، زيارات منجزة، راتب شهري، تقييم
  - الطلبات المتاحة (Active): قبول الطلبات
  - طلباتي: الطلبات الجارية/المنجزة + زر "تم إنجازه"
  - الملف الشخصي، الأرباح، التقييمات

### 👤 المريض
- **التسجيل:** اسم، تليفون، إيميل، عنوان، جنس، باسورد + موافقة على إخلاء المسؤولية
- بعد التسجيل مباشرة:
  - اختيار خدمات متعددة (Multi-select) بأسعار
  - اختيار المنطقة ورسوم المواصلات
  - تنبيه الإلغاء (رسوم بعد 10 دقائق)
  - طلباتي، الملف الشخصي (تعديل العنوان فقط)

### 🛡️ الأدمن
- **تسجيل الدخول:** من صفحة Login باختيار "المدير العام"
- **قفل الجلسة:** لا يفتح إلا في مكان واحد
- طلبات الانضمام (موافقة/رفض)
- إدارة الممرضين (تعديل/حذف)
- إدارة المرضى
- الإعدادات والأسعار (إضافة/حذف خدمات ومناطق)
- الطلبات: نشطة / جاري المعالجة / منجزة / ملغية
- **صلاحية كاملة:** تعديل/إلغاء/إرجاع الطلبات (باستثناء المنجزة التي يمكن إرجاعها فقط)
